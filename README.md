# MySQL DDL Commands & Constraints – Employee Database
📖 ## Overview

This project is a MySQL database assignment designed to demonstrate the use of DDL (Data Definition Language) commands and SQL constraints.

The project creates an employee database containing three related tables:

Departments
Location
Employees

The assignment demonstrates how to create, modify, rename, truncate, and drop database objects while maintaining data integrity through appropriate constraints.

## 🎯Assignment Objectives

The objectives of this assignment are to:

Create an employee database.
Create Departments, Location, and Employees tables.
Apply primary key, foreign key, unique, not-null, check, default, and auto-increment constraints.
Alter the structure of the Employees table.
Rename existing tables.
Truncate the Employees table.
Drop the Employees table.
Drop the complete employee database.

## Constraints

The following constraints are used in this project.

Constraint	Purpose
PRIMARY KEY	Ensures that each record has a unique identifier
NOT NULL	Prevents a column from containing NULL values
UNIQUE	Prevents duplicate values
CHECK	Restricts values based on a specified condition
DEFAULT	Automatically provides a value when none is specified
FOREIGN KEY	Establishes a relationship between tables
AUTO_INCREMENT	Automatically generates sequential numeric values

## ✅Conclusion

This project demonstrates the fundamental MySQL DDL commands and constraints using an Employee Database.

The Departments, Location, and Employees tables demonstrate how related tables can be designed using primary keys and foreign keys. Additional constraints such as NOT NULL, UNIQUE, CHECK, DEFAULT, and AUTO_INCREMENT ensure that the database maintains data integrity, consistency, and reliability.

Overall, this assignment provides practical experience with creating and managing relational database structures using MySQL.
